# 支持键盘修饰键多选与批量粘贴

## Goal

不增加复选框，通过标题栏多选按钮和 Ctrl/Cmd、Shift 点击形成 Windows 文件列表式选择，并在一次操作中把所选文本按列表顺序以换行拼接后粘贴。

## Background

- 当前列表仅保存一个 `selectedId`，左键按下会按 `autoPaste` 配置立即粘贴或复制；证据：`src/pages/Clipboard/components/List.tsx:85`、`src/pages/Clipboard/components/List.tsx:972`。
- 列表使用虚拟滚动和范围缓存，文本正文在列表查询中被裁剪；批量粘贴必须由 Rust 按当前查询顺序读取完整正文。
- 现有粘贴命令一次只处理一个 item，并负责写回、记录复用和模拟粘贴；批量操作应复用同一套窗口隐藏、固定态和回写保护语义。

## Requirements

### R1 - 选择语义

- 多选模式关闭时，普通单击清除多选并恢复现有单击行为。
- 标题栏多选按钮进入/退出显式多选模式。
- 多选模式开启后，普通单击追加选择且不触发粘贴；Ctrl/Cmd+单击切换单项。
- Ctrl+单击（macOS 为 Cmd+单击）：切换当前记录的选择状态，不触发粘贴/复制。
- Shift+单击：以最近一次普通/Ctrl 点击记录为锚点，选择锚点到当前记录之间的连续范围；再次 Shift+单击以同一锚点重新计算范围。
- Shift+单击替换现有选择为目标范围；Ctrl/Cmd+Shift+单击把目标范围追加到现有选择（与 Windows 文件列表一致）。
- 选择状态使用现有 `bg-ant-blue-1` / `border-ant-primary` 等 token 表达；当前键盘焦点仍应有清晰但可区分的视觉状态。
- 筛选、搜索、排序、分组变化或记录被删除时，清理失效选择；不得把不可见旧记录带入批量粘贴。

### R2 - 批量粘贴

- 多选存在时，Enter 或双击已选记录执行批量粘贴。
- 批量粘贴按当前列表顺序拼接，使用单个 `\n` 分隔，写入一次系统剪贴板，只模拟一次粘贴。
- 拼接内容使用各文本记录的 OS 纯文本表示；HTML/RTF 记录不把源码拼入结果。
- 批量粘贴复用粘贴设置决定窗口隐藏/固定态、复用计数和回写抑制，不能产生多条回环记录。
- 选择只有一项时保持单条粘贴行为。
- 新增“支持文本和图片混合粘贴（实验性）”子开关，默认关闭，并补齐中英文偏好文案。
- 子开关关闭时，只有全部选择均为文本族记录才能批量粘贴；图片/文件不得通过摘要或路径隐式混入文本结果。
- 子开关开启且选择仅含文本族记录时，仍走一次写回、一次模拟粘贴，不退化为逐条粘贴。
- 子开关开启且选择包含图片或文件时，按当前列表顺序逐条写回并模拟粘贴；相邻的连续文本族记录应合并为一个换行分隔的文本块，以减少粘贴次数和目标应用时序风险。
- 混合逐条粘贴为实验性能力，任何一步失败时停止后续步骤并给出明确反馈；已完成步骤不回滚，因为外部应用可能已经接收内容。

### R3 - 兼容性

- 无修饰键单击、双击、中键、数字快捷粘贴、右键菜单、备注、拖拽、收藏、置顶、删除均保持当前语义。
- Ctrl/Cmd+C 在多选时复制拼接后的纯文本；混选复制不属于 MVP。

## Acceptance Criteria

- [ ] Ctrl/Cmd+单击可独立切换多项，且不会触发原有单击粘贴/复制。
- [ ] Shift+单击可选择连续范围，并以锚点重新计算范围。
- [ ] 多选项视觉可辨认，焦点项与多选范围不混淆。
- [ ] Enter 和双击均可一次粘贴所选文本，顺序与当前列表一致，换行分隔。
- [ ] 粘贴只调用一次系统粘贴，且只写回一个文本剪贴板载荷。
- [ ] 实验性混选开关默认关闭；关闭时仅当全部选择都是文本族记录才可批量粘贴。
- [ ] 开启混选后，含图片/文件的列表按顺序逐条粘贴，相邻文本连续段合并，全文本选择仍只粘贴一次。
- [ ] 混合逐条粘贴失败时停止后续粘贴并提示失败位置，不声称已完整成功。
- [ ] 选择变化、窗口重开、筛选变化后不会残留不可见旧选择。
- [ ] 单条点击与批量操作之外的所有既有交互回归通过。

## Out of Scope

- 不把图片 OCR、缩略图或文件名自动转成文本参与拼接。
- 混合逐条粘贴不承诺事务原子性，无法撤回外部应用已经接收的前序内容。
