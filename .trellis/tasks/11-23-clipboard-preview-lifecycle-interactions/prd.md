# 修复预览框生命周期并增强预览交互

## Goal

让悬停预览准确跟随当前指针目标并可靠关闭；在不牺牲列表虚拟化与既有窗口定位的前提下，为长文本提供移入面板后滚动、选择、复制的能力，为图片提供移入面板后滚轮缩放的能力。

## Background

- 用户已遇到：预览展开后快速切换软件或快速经过其他记录时，预览框可能不消失；只有再次触发可预览记录时才更新。
- 上一次预览稳定性任务只优化了同一记录内不重复刷新、连接线几何和首次图片尺寸，没有覆盖指针快速跨记录/跨应用和整个触控板工作区被预览 overlay 覆盖的问题。
- 预览 overlay 目前忽略所有鼠标事件，面板无法独立接收 hover、wheel、选择或复制；证据：`src-tauri/src/window/preview.rs:370`、`src-tauri/src/window/preview.rs:377`。
- 当前隐藏缓冲为 240ms，Windows 预览窗口退出动画约 160ms；证据：`src/pages/Clipboard/hooks/previewController.ts:13`、`src/pages/Preview/constants.ts:20`。

## Requirements

### R1 - 生命周期可靠性

- 指针离开当前记录后，若进入无需预览的记录，必须在悬停隐藏缓冲到期后关闭旧预览。
- 指针直接移出剪贴板窗口或应用失焦时，预览必须关闭；不能依赖下一次可预览记录触发。
- 快速跨越多个记录时，只保留最后一次有效预览意图，旧请求不得在关闭后重新显示。
- 预览窗口完全不遮挡用户对底层应用的鼠标操作，除非指针已进入当前实际面板区域。

### R2 - 长文本交互

- 指针从触发记录移入预览面板时不触发关闭；离开“记录 + 面板”联合区域后按正常缓冲关闭。
- 长文本预览可滚动；支持鼠标拖选、Ctrl/Cmd+A、复制，文本需使用 `select-text` 语义并避免虚拟行卸载导致选区丢失。
- 文本预览高度按内容自然伸缩；上限与剪贴板列表高度一致，内容完整可见时不显示纵向滚动条。
- 文本高度使用实际 textarea `scrollHeight` 补偿，避免只差几像素仍出现滚动条。
- 左右布局的连接点锚定剪贴板窗口外边界，不得侵入列表条目。
- 交互增强不得让短文本、文件列表或默认不可交互模式出现布局跳变。

### R3 - 图片缩放

- 指针移入图片面板时预览保持打开。
- 滚轮向上放大、向下缩小，缩放围绕指针位置或面板中心稳定进行；达到最小/最大倍率时停止。
- 关闭后再次打开同一图片恢复默认适配尺寸，不跨会话保留缩放。
- 缩放同时改变预览面板和图片显示，不改历史原图、不触发剪贴板写入。
- 图片缩放可超过默认 480 面板尺寸，按显示器可用区域等比扩缩；每次重新打开恢复默认。
- 支持触摸板捏合产生的 `Ctrl + wheel` 缩放事件。

### R4 - Windows 实机回归修正

- 左右两侧连接线必须使用同一套列表行 DOM 边界；圆点应完整落在列表与预览面板外侧，不得侵入条目。
- Windows 精确触摸板的原生捏合手势不得被 WebView2 吞掉；系统原生手势、双指触点和 `Ctrl + wheel` 三条路径均可驱动图片面板整体等比缩放。
- 文本预览在展开动画和首次真实高度测量期间不得闪现滚动条；初始估算需留出安全余量，动画稳定后再按真实溢出显示滚动条。

## Acceptance Criteria

- [ ] 从长文本预览快速移入短文本、空白、另一应用时，旧预览在缓冲后消失且不会闪回。
- [ ] 快速跨多个记录时只显示最后一个目标，异步返回顺序不会复活旧预览。
- [ ] 指针从记录跨过间隙进入预览面板后，面板保持打开。
- [ ] 长文本面板可滚动，拖动可形成稳定选区，Ctrl/Cmd+C 可复制所选内容。
- [ ] 短文本使用较矮的动态面板；长文本增高到列表高度上限后才出现滚动条。
- [ ] 图片面板可滚轮缩放，关闭并重新打开后恢复适配尺寸。
- [ ] 面板外仍可正常点击/滚动底层应用；预览窗口不会整屏拦截输入。
- [ ] Space 预览、左右/上下定位、连接线与首次图片尺寸仍正常。
- [ ] Windows 实机验证主路径；macOS 完成同等编译与可执行验证或明确记录受环境限制。
- [ ] 左右两侧连接线分别贴合剪贴板窗口外边缘，连接圆点不侵占列表项或预览面板。
- [ ] Windows 精确触摸板捏合可以缩放图片，且滚轮缩放保持原有行为。
- [ ] 短文本和全部可见文本在预览展开过程中不出现滚动条闪现。
