# 可选修复纯图片复制后无法粘贴

## Goal

提供一个默认关闭的兼容开关：当某些电脑截图后只发布不完整/非标准图片剪贴板格式，导致首次直接粘贴失败时，EcoPaste 在捕获纯图片后自动规范化为可粘贴的图片格式；同时严格保留 Excel/WPS 表格复制的多格式语义。

## Background

- 用户观察到截图后直接粘贴失败，而先通过 EcoPaste 历史记录再次写回同一图片后即可粘贴，说明“重新写回”会生成接收方需要的标准图片格式组合。
- 当前图片读取优先读取 PNG，其他 TIFF/DIB 等由库解码后再编码 PNG；证据：`src-tauri/src/clipboard/read.rs:142`。
- 当前图片写回使用 `set_image`，Office 图片记录还会追加纯文本表示；证据：`src-tauri/src/clipboard/write.rs:117`。
- Office/WPS 已通过来源识别保留纯文本备用表示，默认粘贴写“图片 + 文本”，纯文本粘贴只写文本；证据：`src-tauri/src/clipboard/read.rs:182`、`src-tauri/src/clipboard/write.rs:37`。
- 已发布设置使用 serde 默认值扩展，新开关必须默认 `false`，避免升级后主动改写用户剪贴板。

## Requirements

### R1 - 设置

- 新增默认关闭的用户设置与中英文标题、描述、搜索关键词和图标。
- 设置修改后立即影响下一批剪贴板事件，无需重启。
- 关闭开关时零额外格式检测、零额外剪贴板写入。
- 该能力仅在 Windows 提供和生效；macOS 不显示该设置，也不执行图片格式修复。

### R2 - 纯图片识别与修复

- 仅在监听事件最终归类为 `Image` 且不存在 Office/WPS 表格文本语义时触发修复。
- 历史记录仍按原流程入库；修复在入库决策完成后执行，避免历史类型被 switch 改变。
- 修复需要先判定现有系统剪贴板格式是否缺少接收方常用支持（至少验证标准位图/PNG 可用性），只有缺失或明显不完整时才重写。
- 重写后保持图片像素和尺寸不变，并登记写回 guard，避免 watcher 再次入库回环。
- 修复失败只记录日志，不影响本次历史入库和用户界面。

## Acceptance Criteria

- [ ] 设置默认关闭，旧配置文件升级后自动得到 `false`。
- [ ] 设置只在 Windows 偏好页显示；macOS 不暴露无效开关，也不执行修复逻辑。
- [ ] 关闭时纯图片复制行为与当前版本一致。
- [ ] 开启后，PNG-only 纯图片截图用例完成入库，并在缺少原生位图格式时被修复为可粘贴格式。
- [ ] 修复后 watcher 不新增重复记录，图片像素尺寸不变化。
- [ ] Excel/WPS 表格复制不被修复路径改写，普通粘贴与纯文本粘贴均保持现有格式组合。
- [ ] 无双格式文本的普通图片仍可正常保存、预览、复制和粘贴。
- [ ] 修复逻辑具备 Windows 平台边界测试并完成 Windows 实机截图验证；macOS 编译与现有图片链路回归通过。
